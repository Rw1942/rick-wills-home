# Product Brief

## Vision

Build a minimal personal project portfolio site that is simple to read and easy to maintain.

## Audience

- People reviewing your past work
- Potential collaborators or employers
- Anyone you share your portfolio link with

## Functional Requirements

## Project List Page

Each project entry must include:
- `title`
- `date`
- `description`

Each entry must link to a project detail page.

## Project Detail Page

Each detail page must include:
- Project title
- Project date
- Longer write-up
- One or more screenshots

## Screenshot Handling

- Screenshots are uploaded into a static folder
- Project pages reference screenshots by stable file paths
- Images should include useful alt text

## Design Constraints (Mandatory)

- White background
- Default-looking typography
- Very plain layout
- Minimal spacing and ornamentation
- Avoid visual effects, heavy styling, and complex components

## Non-Goals

- No authentication
- No database
- No CMS
- No advanced animation
- No framework complexity unless explicitly requested later

## Success Criteria

- A visitor can scan the project list quickly
- A visitor can click any project and view screenshots plus additional writing
- The site feels intentionally minimalist and remains easy to update
